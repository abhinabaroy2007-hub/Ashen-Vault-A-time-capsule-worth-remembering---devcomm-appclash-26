# Ashen Vault

> Leave a silent whisper for the soul you become.

Ashen Vault is a time capsule app that lets you lock photos, videos, and voice notes into a relic, then revisit those memories after its countdown ends. It is built natively with SwiftUI and SwiftData for iOS.

## Build and run

1. Open `AshenVault.xcodeproj` in Xcode.
2. Choose an iPhone or iPad simulator and press Run.
3. To install on a physical device, connect it and select your Apple Development team under **Signing & Capabilities**. A free Apple ID can sign for personal testing; App Store distribution requires the Apple Developer Program.

Requires Xcode 27 or compatible, iOS 17 or later. The app requests microphone access for voice recording and photo library access when you select media.
