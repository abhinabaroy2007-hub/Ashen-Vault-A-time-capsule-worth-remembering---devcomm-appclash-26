# Ashen Vault

A native SwiftUI time capsule app for iOS. Create time-locked relics containing photos, videos, notes, and voice recordings, then revisit them when their countdown ends. The project includes pixel-art backgrounds, ambient fire audio, sound effects, and haptic feedback.

## Build and run

1. Open `AshenVault_WithAddedAudio&Haptics.xcodeproj` in Xcode.
2. Select the AshenVault app scheme and an iOS Simulator or connected iPhone/iPad.
3. For a physical device, select your Apple Development team under **Signing & Capabilities**, then press Run.

The app uses microphone access for voice recordings and local notifications for relic unlock reminders.
